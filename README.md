### TAOS Launcher

The TAOS Launcher is the entry point of the TAOS pipeline. It is responsible for configuring and launching DCC applications with the correct production environment.

Features
Set up environments for Maya, 3ds Max, Houdini, and other DCC applications.
Manage project-specific environment variables.
Automatically load TAOS plugins, packages, and pipeline tools.
Support multiple software versions and project configurations.
Ensure a consistent and reproducible production environment across the team.

By centralizing environment configuration and tool loading, the launcher simplifies pipeline management and allows artists to start working without manual setup.
